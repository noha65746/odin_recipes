# odin_recipes

This project is a simple recipe website created with HTML and CSS as part of **The Odin Project Foundations curriculum**.

The website contains 3 recipes. Each recipe has its own page with information about the ingredients and instructions needed to prepare it.

The images are selected from Pixabay by NikkkOO, misjang70, and pzphone.

## Skills Gained

* Basic HTML structure
* Creating multiple web pages
* Using links to navigate between pages
* Adding images to web pages
* Creating lists
* Basic Git
